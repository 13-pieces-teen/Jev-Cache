# 复古界面实装记录

日期：2026-09-27。对应 [UI/UX 设计提案](UIUX-DESIGN.md)。

## 已实现

- 灰黑 Windows 98 风格：窄黑标题栏、立体按钮、矩形凹槽、统一像素内存图标；中文使用本机微软雅黑。
- 三层界面：304 × 94 的悬浮窗、约 440 × 600 的展开面板、940 × 680 的可缩放详情窗口。尺寸是逻辑像素。
- 小悬浮窗直接显示“内存占用 74%”和“可用 4.1 GB · 手动／自动”；数字使用当前采样计算，未取得数据时显示横线。处理中和暂停状态显示在标题栏，悬停可查看已用／总量。上述数字仅为文案示例。
- 悬浮窗、展开面板和详情窗口使用相同的按钮状态：未配置密钥时显示“连接 Jev”，已配置时显示“一键清理”。手动点击直接发起本轮 Jev 判断与清理，不打开其他窗口；点击只授权本轮必要摘要，不修改持久的自动摘要权限或自动模式。按钮提示与设置页说明这一行为。处理中禁用重复点击，小窗立即显示“正在处理”；已暂停且没有在途任务时，点击开始新一轮。此处沿用本地配置状态，不代表持续进行网络连通性探测。
- 日常启动打开小面板；完整窗口通过处理记录、保留名单、记忆和设置入口进入。小面板可按 Esc 或点击外部收起；浮窗可单独隐藏，由托盘恢复。
- 手动入口、自动开关和暂停状态在各窗口同步。重复点击合并，处理中禁用新的清理入口。尚未启用 Jev 时主入口引导配置，保留本地对象查看和单独正常关闭。
- 展开面板可选填写本次需求；开启自动时显示当前已验证文档范围。
- 结果先展示真实动作，再显示有资格的内存观察句。失败、未知、下降与无变化分别呈现；测量按 action_id 关联，避免把同名对象的上一轮数值挪到新动作。
- 处理记录区分完成／等待／未确认；重新打开与本次纠正是独立操作。应用列表支持保留名单过滤。
- 保留项、使用摘要、记忆设置、清除记录、Jev 配置与 Edge 接入继续使用现有能力。设置反馈显示在当前窗口，不用普通成功通知打断全屏应用。

本轮未扩大自动清理范围。逐条 Jev 理由、实际引用的记忆解释、逐条习惯编辑仍需相应数据支持，界面没有填入推测内容。靠边自动缩成窄条和完整多屏恢复仍待进一步完善；当前可拖动、限制在有效屏幕内、手动收起及全屏隐藏。

## 运行

源码运行仍使用 `scripts/start.ps1`。完整常规构建仍使用 `scripts/build.ps1`，已接入新的可执行文件图标。

本轮独立构建位于 `dist/visual-preview/JevCache/JevCache.exe`，附带浏览器宿主、扩展和接入说明。保留原 `dist/JevCache` 目录，避免覆盖正在运行的旧程序。两者使用同一套默认用户配置和单实例锁；试用新版前，请从旧版托盘选择“退出助手”，再打开新版。

当前桌面版本位于 `dist/floating-action/JevCache/JevCache.exe`，已包含手动一键清理直接执行的更新。32 项 UI / Runtime / 策略检查及 9 项界面检查通过：覆盖大小窗口不弹出、重复点击合并、暂停后新一轮、按次摘要许可不持久化、不授予自动上传权限，以及判断结果进入原有执行检查。网络和执行使用受控替身，检查未请求真实 Jev 或清理用户应用。

界面样例复现：

```powershell
.venv\Scripts\python.exe scripts/preview_ui.py --output artifacts/ui-retro
$env:QT_SCALE_FACTOR = '1.5'
.venv\Scripts\python.exe scripts/preview_ui.py --output artifacts/ui-retro-150
Remove-Item Env:\QT_SCALE_FACTOR
```

## 代码位置

- `src/jev_cache/ui_theme.py`：颜色、文字、控件和窗口主题。
- `src/jev_cache/ui_widgets.py`：标题栏、内存条、结果组件、悬浮窗。
- `src/jev_cache/ui_panels.py`：共享操作区、紧凑展开面板。
- `src/jev_cache/ui.py`：详情窗口、设置及现有操作绑定。
- `src/jev_cache/presentation.py`：来自真实状态和回执的展示转换，不拥有执行权限。
- `runtime.py` 增加阶段／压力展示、测量动作关联，以及手动请求的按次摘要授权；自动摘要许可仍单独检查，候选筛选和执行边界保持原实现。

尚未执行真实清理收益对照。源码、设计稿与复现脚本纳入仓库，本机运行截图、状态数据及打包产物不纳入 Git。
