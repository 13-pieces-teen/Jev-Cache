# Jev-Cache · 三分钟交互 Demo

[打开在线版本](https://jev-cache-demo.ag2sag2sliu.chatgpt.site)

[完整三分钟讲稿](pitch.md)

离线播放：下载或克隆本仓库，双击本目录的 `index.html`。文件自包含，无需 Node.js、API Key 或网络连接；GitHub 文件预览不会执行网页，需下载后在浏览器打开。

- 「播放 3 分钟」：180 秒、六幕场景，配中文字幕。
- 顶部章节／左右方向键：逐幕切换；空格暂停／播放，Home 返回开头。
- 「讲稿」或 N：显示当前幕口播提示。
- 「自由演示」：切换任务、内存压力、自动模式和反馈，观察预期结果。
- 「演示说明」：查看实现基础与模拟范围。
- 支持 `?t=80` 跳到指定秒数，`?notes=1` 默认显示讲稿。

**所有状态、判断和收益数字均为脚本模拟。** Demo 不调用 Jev，不读取电脑状态，不执行真实清理；动画时间也不作为请求延迟、内存收益或模型质量的证据。实际已实现范围见[仓库 README](../../README.md#当前支持范围)。

此离线快照于 2026-09-27 从项目已有演示同步，仅添加到仓库供访客使用；未改变演示逻辑。
